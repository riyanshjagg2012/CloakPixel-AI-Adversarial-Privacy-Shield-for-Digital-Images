# CloakPixel-AI-Adversarial-Privacy-Shield-for-Digital-Images
CloakPixel AI: On-device adversarial privacy shield that protects photos from unauthorized facial recognition and deepfakes. Using PyTorch, ONNX, and facial landmarks, it injects invisible, JPEG-resistant pixel perturbations (>0.98 SSIM) that drop AI scraper match confidence below 20% with zero cloud uploads.
